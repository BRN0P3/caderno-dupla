Dicas de Git

  1. git status = Ver o que mudou.
  2. git add = Preparar alterações.
  3. git commit = Salvar as alterações no histórico.
  4. git push = Enviar alterações para o repositório remoto.
  5. git pull = Baixar alterações do repositório remoto.
  6. git clone = Baixar um repositório existente.
  7. git log = Ver o histórico de alterações.
  8. git branch = Trabalhar com diferentes linhas de desenvolvimento.
  9. git switch = Trocar de branch.
  10. git merge = Juntar as alterações de uma branch em outra.
  11. git reset = Voltar ao estado anterior.
